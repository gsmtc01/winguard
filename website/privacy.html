WinGuard 개인정보 처리방침

최종 개정일: 2026년 8월 15일
적용 버전: WinGuard 0.1.0 이상

요약

WinGuard는 서버를 운영하지 않습니다. 회원가입, 로그인, 계정이 존재하지 않으며, 이용자의 개인정보를 개발자에게 전송하거나 수집·보관하지 않습니다. 점검 결과와 AI 분석은 전부 이용자 기기 안에서 처리되고, 생성된 데이터는 이용자 기기의 로컬 폴더에만 저장됩니다.

다만 일부 기능(VirusTotal 파일 검사, AI 모델 다운로드, 업데이트 확인, 지원 종료일 조회)은 그 성격상 제3자 서비스와의 통신을 수반합니다. 이 부분은 제5조에 상세히 기술되어 있습니다.

제1조 (총칙)

개인 개발자 DONGHUN OH(이하 "개발자")는 Windows 전용 보안 상태 점검 소프트웨어 WinGuard(이하 "본 소프트웨어")의 이용자 개인정보를 중요하게 생각하며, 개인정보 보호법 등 관계 법령을 준수합니다. 본 방침은 본 소프트웨어가 어떤 정보를 어떻게 다루는지를 이용자에게 투명하게 알리기 위하여 수립되었습니다.

제2조 (개인정보의 수집 여부)

  1. 개발자는 본 소프트웨어를 통하여 이용자의 개인정보를 수집하지 않습니다.
  2. 본 소프트웨어에는 다음 요소가 존재하지 않습니다.
    • 이용자 계정, 회원가입, 로그인 절차
    • 사용 통계, 텔레메트리, 행동 분석, 광고 식별자 수집 기능
    • 개발자가 운영하는 백엔드 서버 또는 데이터베이스
    • 오류 보고(Crash Report)의 자동 전송
  3. 본 소프트웨어가 생성하는 모든 데이터는 이용자 기기의 로컬 저장소에 한정하여 존재합니다.

제3조 (기기 내에서 처리되는 정보의 범위)

본 소프트웨어는 보안 점검 기능 수행을 위하여 이용자 기기의 다음 정보를 읽습니다. 아래 정보는 기기 내부에서만 처리되며, 이용자가 제5조의 외부 전송 기능을 직접 실행하지 않는 한 외부로 전송되지 않습니다.

구분처리 대상

소프트웨어 상태Windows 및 Office 지원 종료(EOL) 여부, 업데이트 적용 상태, PowerShell 실행 정책, 자동 실행(Autorun) 항목, 설치된 브라우저 및 확장 프로그램 목록

기능처리 대상

위 정보 중 일부(예: 실행 경로, 사용자 프로필 경로, 계정명)에는 이용자 또는 이용자 기기를 식별할 수 있는 문자열이 포함될 수 있습니다. 이러한 정보 역시 로컬에서만 처리됩니다.

제4조 (로컬 저장 위치 및 보유 기간)

데이터저장 위치보유 기간
검사 기록, 보안 점수 히스토리, 테마 설정%LOCALAPPDATA%\com.winguard.security\이용자가 삭제할 때까지
AI 모델 경로, 업데이트 설정%LOCALAPPDATA%\WinGuard\이용자가 삭제할 때까지
조치 전 레지스트리 원본값 백업(격리)%LOCALAPPDATA%\WinGuard\quarantine\이용자가 삭제할 때까지. 단, 항목이 50개를 초과하면 오래된 항목부터 자동 정리
AI 모델 파일 (약 2.89 GiB)%LOCALAPPDATA%\WinGuard\models\ 또는 이용자가 지정한 경로이용자가 삭제할 때까지
VirusTotal API 키Windows 자격 증명 관리자(Credential Manager)이용자가 삭제할 때까지
  1. VirusTotal API 키는 평문 설정 파일이 아니라 운영체제가 제공하는 자격 증명 관리자에 저장되어, 운영체제 수준의 보호를 받습니다.
  2. 이용자는 앱 설정 화면에서 검사 기록, 격리 백업, AI 모델 파일을 삭제할 수 있으며, 위 폴더를 직접 삭제하여 데이터 전체를 파기할 수 있습니다.
  3. 본 소프트웨어는 포터블 실행 파일이므로, 위 폴더를 삭제하고 실행 파일을 제거하면 이용자 기기에 잔존 데이터가 남지 않습니다.

제5조 (제3자 서비스로의 통신)

다음 기능은 그 성격상 외부 서버와의 통신을 필요로 합니다. 모든 HTTPS 통신에는 이용자의 IP 주소와 User-Agent 등 통신에 필연적으로 수반되는 정보가 각 서비스 제공자에게 전달되며, 해당 정보의 처리는 각 사업자의 개인정보 처리방침에 따릅니다.

5.1 VirusTotal 파일 검사 (이용자가 API 키를 등록한 경우에만 동작)

항목내용
전송 대상VirusTotal (Google LLC 계열, 미국)
전송 정보 (해시 조회)검사 대상 파일의 SHA-256 해시값
전송 정보 (업로드 검사)검사 대상 파일 원본 전체
조건이용자가 API 키를 입력하고 검사를 직접 실행한 경우

중요. 해시 조회 결과가 존재하지 않는 파일에 대하여 업로드 검사를 허용하면, 파일 원본이 VirusTotal 서버로 전송됩니다. VirusTotal은 업로드된 파일을 보안 업계 및 유료 구독자에게 공유할 수 있습니다. 따라서 개인정보, 영업비밀, 기밀문서가 포함된 파일은 업로드해서는 안 됩니다. 업로드는 이용자가 명시적으로 허용한 경우에만 수행되며, 기본값은 업로드하지 않는 것입니다.

5.2 AI 모델 다운로드

항목내용
통신 대상HuggingFace (미국)
전송 정보다운로드 요청 정보(IP 주소, User-Agent 등)
조건이용자가 AI 분석 기능을 최초로 사용하여 모델 다운로드를 승인한 경우

모델 파일은 실행 파일에 포함되어 있지 않으며, 다운로드 요청 시 점검 결과나 기기 정보는 전송되지 않습니다.

5.3 업데이트 확인 및 내려받기

항목내용
통신 대상GitHub API (api.github.com) 및 GitHub Releases
전송 정보요청 정보(IP 주소, WinGuard-Updater User-Agent 등)
조건이용자가 업데이트 확인을 실행한 경우

자동 다운로드 및 자동 설치는 수행되지 않으며, 다운로드 주소는 GitHub 호스트로 제한되고 SHA-256 검증을 통과한 경우에만 실행 파일이 교체됩니다.

5.4 버전 및 지원 종료일 정보 조회

통신 대상목적
endoflife.dateWindows 및 Office의 지원 종료일 조회
versionhistory.googleapis.comChrome 최신 버전 조회
product-details.mozilla.orgFirefox 최신 버전 조회

위 요청은 공개된 버전 정보를 내려받는 단방향 조회이며, 이용자 기기의 점검 결과나 설치 목록은 전송되지 않습니다. 조회한 값과 로컬 버전의 비교는 기기 내부에서 수행됩니다.

제6조 (AI 분석과 온디바이스 처리)

  1. 본 소프트웨어의 AI 분석은 Google Gemma 4 E2B Instruct(Q4_K_M 양자화) 모델을 이용자 기기 내부에서 직접 실행하는 방식으로 동작합니다.
  2. 점검 결과, 프로세스 목록, 네트워크 연결 정보 등 AI에 입력되는 데이터는 외부 API로 전송되지 않으며, 추론 과정 전체가 로컬에서 완결됩니다.
  3. 따라서 AI 분석 기능의 사용은 제5조의 외부 전송에 해당하지 않습니다. 다만 모델 파일의 최초 다운로드는 제5조 제2항의 통신을 수반합니다.

제7조 (국외 이전)

제5조에 기재된 통신 대상은 모두 국외(주로 미국)에 소재한 사업자입니다. 개발자는 이용자의 개인정보를 국외로 이전하지 않으나, 이용자가 해당 기능을 직접 실행하는 경우 통신 과정에서 IP 주소 등이 국외 사업자에게 전달됩니다. 이용자는 해당 기능을 사용하지 않음으로써 이러한 통신을 회피할 수 있습니다.

제8조 (권한 및 안전성 확보 조치)

  1. 본 소프트웨어는 시스템 보안 설정의 조회 및 변경을 위하여 관리자 권한으로 실행됩니다. 이는 Windows 보안 정책상 필요한 최소한의 권한이며, 권한 상승은 실행 시점에 Windows UAC를 통하여 이용자에게 고지됩니다.
  2. 조치 실행 전 원본 레지스트리 값을 반드시 백업하며, 백업에 실패하면 조치를 중단합니다.
  3. 인증정보(VirusTotal API 키)는 운영체제의 자격 증명 관리자에 저장하여 평문 노출을 방지합니다.
  4. 배포되는 실행 파일에는 현재 코드 서명이 적용되어 있지 않으므로, 이용자는 릴리즈에 게시된 .sha256 값과 대조하여 파일 무결성을 확인할 것을 권장합니다.
Get-FileHash .\WinGuard-x64.exe -Algorithm SHA256
  1. 개발자는 이용자 기기에 저장된 로컬 데이터에 접근할 수 없으므로, 해당 데이터의 물리적·논리적 보호 책임은 이용자 기기의 보안 상태에 의존합니다.

제9조 (이용자의 권리)

  1. 개발자가 보유하는 이용자의 개인정보가 존재하지 않으므로, 개인정보 보호법상 열람·정정·삭제·처리정지 요구의 대상이 되는 보유 정보는 없습니다.
  2. 이용자는 제4조에 기재된 로컬 데이터를 언제든지 스스로 열람하고 삭제할 수 있습니다.
  3. 제5조의 외부 서비스에 전달된 정보에 대한 권리 행사는 각 사업자의 정책에 따라 해당 사업자에게 직접 요구하여야 합니다.

제10조 (만 14세 미만 아동의 개인정보)

본 소프트웨어는 개인정보를 수집하지 않으므로 아동의 개인정보를 별도로 수집하거나 법정대리인의 동의를 받지 않습니다. 다만 본 소프트웨어는 관리자 권한으로 시스템 설정을 변경하는 도구이므로, 만 14세 미만 아동은 보호자의 감독하에 사용할 것을 권장합니다.

제11조 (제3자 서비스 정책 참조)

각 서비스의 개인정보 처리에 관한 사항은 아래 사업자의 정책을 참조하시기 바랍니다.

  • VirusTotal 및 Google
  • Hugging Face
  • GitHub 및 Microsoft
  • Mozilla
  • endoflife.date

제12조 (개인정보 처리방침의 변경)

본 방침이 변경되는 경우 개발자는 본 페이지에 개정 내용과 적용일자를 게시합니다. 이용자의 권리에 중대한 영향을 미치는 변경의 경우 릴리즈 노트를 통하여 함께 안내합니다.
