소개 공지사항 업데이트 소식 Q&A 다운로드

무엇을 도와드릴까요?

WinGuard는 어떤 Windows 버전에서 사용할 수 있나요?

Windows 11(x64, ARM64)을 지원합니다. 최소 800×600, 권장 1100×720 해상도에서 사용하실 수 있습니다.

설치가 필요한가요?

설치 과정이 없습니다. 아키텍처에 맞는 실행 파일 하나를 받아 그대로 실행하면 됩니다. 트레이에 상주하는 경량 앱입니다.

실행할 때 관리자 권한이 필요한가요?

네. 일부 점검과 수정 기능이 관리자 권한을 사용하기 때문에, 실행할 때마다 Windows UAC 확인 창이 나타납니다. 여기서 '예'를 눌러야 앱이 시작됩니다.

실행하려니 SmartScreen 경고가 떠요.

현재 실행 파일에 코드 서명이 적용되어 있지 않아 'Windows의 PC 보호' 경고가 나타날 수 있습니다. 다운로드 페이지의 SHA-256 값으로 파일을 먼저 확인한 뒤, '추가 정보' → '실행'을 눌러 진행하세요.

23개 보안 점검 항목에는 어떤 것들이 포함되나요?

Windows Defender, 방화벽, BitLocker, UAC, Secure Boot, TPM 같은 기본 보안 설정과 함께, DNS 하이재킹 · 랜섬웨어 흔적 · hosts 파일 변조 · SMBv1 활성화 · 레지스트리 변조(PUM) 같은 침해 징후를 점검합니다.

보안 점수는 어떻게 계산되나요?

100점에서 시작해 항목의 심각도만큼 감점합니다. 경고 −10점, 위험 −20점, 심각 −35점이며 0점 아래로는 내려가지 않습니다. 정상과 정보 항목은 감점되지 않습니다.

점검 결과를 파일로 저장할 수 있나요?

대시보드의 '내보내기'에서 점검 항목 전체를 CSV로 저장하거나, AI가 작성한 보안 보고서를 Markdown(.md)으로 저장할 수 있습니다.

온디바이스 AI 분석이란 무엇인가요?

Google Gemma 4 E2B 기반 로컬 LLM 이 기기 내부에서 점검 결과와 로그를 해석합니다. 추론이 전부 PC 안에서 이뤄지므로 분석 대상 데이터가 외부로 전송되지 않습니다.

AI 분석에 인터넷 연결이 필요한가요?

추론에는 필요하지 않습니다. 다만 AI 분석을 처음 사용할 때 모델 파일을 한 번 내려받아야 하며, 이때만 인터넷 연결이 필요합니다.

AI 모델 파일은 얼마나 큰가요? 어디에 저장되나요?

Gemma 4 E2B Instruct(Q4_K_M 양자화) 약 2.89 GiB 이며, HuggingFace 에서 직접 내려받습니다. 기본 저장 위치는 %LOCALAPPDATA%\WinGuard\models\ 이고 앱에서 다른 폴더로 바꿀 수 있습니다. 필요 없어지면 설정에서 삭제할 수 있습니다.

제 파일이나 로그가 외부 서버로 전송되나요?

보안 점검과 AI 분석은 전부 기기 안에서 이뤄집니다. 외부와 통신하는 경우는 네 가지입니다. VirusTotal 파일 검사, AI 모델 내려받기, 업데이트 확인, 그리고 Windows·Office 지원 종료일과 브라우저 최신 버전 조회입니다. 앞의 세 가지는 이용자가 직접 실행한 경우에만 동작하며, 마지막 조회는 공개된 버전 정보를 받아오는 단방향 요청이라 기기의 점검 결과나 설치 목록이 전송되지 않습니다. 자세한 범위는 개인정보 처리방침 제5조에 정리되어 있습니다.

VirusTotal 검사에 파일을 올려도 안전한가요?

해시 조회만 하는 경우에는 파일의 SHA-256 값만 전송됩니다. 다만 조회 결과가 없는 파일에 대해 업로드 검사를 허용하면 파일 원본 전체가 VirusTotal 서버로 전송되고, VirusTotal 정책에 따라 보안 업계와 유료 구독자에게 공유될 수 있습니다. 개인정보나 영업비밀, 기밀문서가 담긴 파일은 업로드하지 마세요. 업로드는 이용자가 명시적으로 허용한 경우에만 수행되며 기본값은 업로드하지 않는 것입니다.

앱이 만드는 데이터는 어디에 저장되나요?

검사 기록 · 점수 히스토리 · 테마는 %LOCALAPPDATA%\com.winguard.security\ 에, 모델 경로와 업데이트 설정은 %LOCALAPPDATA%\WinGuard\ 에 저장됩니다. VirusTotal API 키는 Windows 자격 증명 관리자에 보관됩니다.

카메라·마이크 접근은 어떻게 제어하나요?

앱 목록에서 장치 접근 권한을 확인하고, 원치 않는 프로그램의 접근을 즉시 차단할 수 있습니다.

WinGuard는 무료인가요?

네. 모든 기능을 무료로 제공하며, MIT 라이선스로 배포되는 오픈소스입니다. 소스 코드는 GitHub 저장소에서 확인하실 수 있습니다.

AI 모델의 라이선스는 어떻게 되나요?

사용하는 Gemma 4 E2B 모델은 Google DeepMind 가 Apache License 2.0 으로 배포한 것입니다. 그 밖의 오픈소스 구성 요소는 저장소의 THIRD-PARTY-NOTICES 문서에 정리되어 있습니다.

문제를 수정했는데 시스템에 이상이 생겼어요. 되돌릴 수 있나요?

레지스트리를 변경하는 조치는 원래 값을 먼저 백업합니다. 백업에 실패하면 조치 자체를 중단하며, Quarantine 에서 언제든 복원할 수 있습니다.

격리 백업은 얼마나 오래 보관되나요?

이용자가 삭제할 때까지 보관됩니다. 다만 항목이 50개를 넘으면 오래된 것부터 자동으로 정리되므로, 장기 보존이 필요한 백업은 따로 보관해두시기 바랍니다.

트레이 아이콘이 보이지 않아요.

작업 표시줄 설정에서 숨겨진 아이콘 표시 옵션을 켜면 트레이 아이콘을 다시 확인하실 수 있습니다.

새 버전으로 어떻게 올리나요?

앱이 새 버전을 확인해 알려주며, 내려받은 파일의 해시를 검증한 뒤 교체하고 재시작합니다. 직접 받고 싶다면 다운로드 페이지에서 최신 파일을 받아 기존 실행 파일을 덮어써도 됩니다.

검색 결과가 없습니다. 다른 검색어를 입력해보세요.
