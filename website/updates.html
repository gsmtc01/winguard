v0.1.0

2026.08.15 최신 버전

Windows 보안 상태 점검 앱 WinGuard의 첫 공개 릴리즈입니다.

신규
  • 23개 상시 보안 점검: DNS 하이재킹, 랜섬웨어 흔적, 레지스트리 변조 탐지 포함
  • 보안 점수를 원형 게이지로 요약
  • 온디바이스 AI 분석: 기기 내부에서만 추론하며 분석 대상이 외부로 전송되지 않습니다
  • 프로세스 / 네트워크 / 이벤트로그 / 브라우저 확장 분석
  • 카메라·마이크 접근 제어
  • VirusTotal 연동 파일 검사
  • 수정 전 자동 백업 및 복원(Quarantine)

알아두실 점. 이 실행 파일은 코드 서명이 되어 있지 않습니다. 실행할 때 Windows SmartScreen이 "Windows의 PC 보호" 경고를 띄울 수 있습니다. 위 해시로 파일을 확인하신 뒤 추가 정보 → 실행을 눌러 진행하세요. 일부 점검과 수정 기능은 관리자 권한을 사용합니다.
