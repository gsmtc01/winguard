WinGuard 다운로드

현재 버전 v0.1.0 · 2026.08.15 배포 · MIT 오픈소스

Windows x64

약 11.6 MB · Intel / AMD 다운로드

Windows ARM64

약 10.5 MB · ARM64 다운로드

시스템 요구사항

  • Windows 11 (x64 / ARM64)
  • 최소 해상도 800×600, 권장 1100×720
  • 실행 시 관리자 권한 필요 (일부 점검·수정 기능이 사용합니다)
  • AI 분석 사용 시 모델 파일 약 2.89 GiB 추가 다운로드 (선택)

설치 가이드

  1. 1

    다운로드

    사용 중인 PC 아키텍처에 맞는 실행 파일을 받습니다. 설치 과정은 없습니다.

  2. 2

    실행

    SmartScreen 경고가 뜨면 '추가 정보' → '실행', 이어서 UAC 확인 창에서 '예'를 누릅니다.

  3. 3

    최초 스캔

    실행 즉시 23종 보안 점검이 자동으로 시작됩니다.

파일 무결성 확인

받은 파일이 맞는지 해시로 확인하세요

이 실행 파일에는 아직 코드 서명이 적용되어 있지 않아, 처음 실행할 때 Windows SmartScreen 경고가 나타날 수 있습니다. 아래 값과 대조해 파일이 변조되지 않았는지 먼저 확인하시길 권합니다. 

Get-FileHash .\WinGuard-x64.exe -Algorithm SHA256
SHA-256 · WinGuard-x64.exe (v0.1.0)
b852c1470cfcad4097267efff4cedfd765934fe9c95a68e9fe39f59500d58f15
SHA-256 · WinGuard-arm64.exe (v0.1.0)
de9e48e37bbbe1b1e167dc99fb33ed804a0f96db6768166551de9af0ace64426

각 릴리즈에는 .sha256 파일도 함께 올라갑니다. 최신 값은 GitHub 릴리즈 페이지에서도 확인할 수 있습니다.

AI 분석은 기기 안에서만 이루어집니다
